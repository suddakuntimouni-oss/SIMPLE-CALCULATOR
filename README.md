# Simple Calculator

## Description

This is a basic Python calculator that performs addition, subtraction, multiplication, and division on two numbers entered by the user.

## Requirements

* Python 3.x

## How to Run

1. Save the program as `calculator.py`.
2. Open a terminal or command prompt.
3. Run:

   ```
   python calculator.py
   ```
4. Enter two numbers and choose an operator (`+`, `-`, `*`, `/`).

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Division-by-zero error handling
